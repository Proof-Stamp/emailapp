# Ready screen CTA

The ready screen should frame the action around the user's ProofStamp rather than the email mechanism.

Current copy:

- Title: **ProofStamp ready**
- Intro: **Your ProofStamp is ready to send.**
- Primary action: **Email ProofStamp**
- Helper: **Your email app will open with it ready to send.**
- Attachment note: **Optional: attach the originals.**

The return flow changes the primary action to **Email ProofStamp again** after an email handoff.
