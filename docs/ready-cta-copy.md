# Ready screen CTA

The ready screen should frame the ProofStamp as complete before the user chooses how to keep it.

Current copy:

- Title: **ProofStamp ready**
- Intro: **Your ProofStamp is ready. Email it, save it, or copy it.**
- Primary action: **Email ProofStamp**
- Helper: **Your email app will open with it ready to send.**
- Attachment note: **Optional: attach the originals before sending.**
- Secondary actions: **Save ProofStamp** and **Copy ProofStamp**

Email is recommended, not required. A recipient address is optional before preparing the ProofStamp. If no address is entered, the user can save or copy the ProofStamp immediately, or open a new email with the ProofStamp body prefilled and choose a recipient there.

The attachment note stays next to the email action and before the longer receipt preview so it is visible at the moment the user is deciding whether to send.

The return flow changes the primary action to **Email ProofStamp again** after an email handoff.
